## Known gaps

1. **2.5.8 target size**: the CSS fix (`fix/a11y-target-size`, PR #184) has since merged to main. The results above are from `ceefa83`, before it. Re-run the wcag22 checks on current main to confirm the CYP chips and in-list pair links.
2. **1.4.12 text spacing at 320 px**: Paxlovid pair pages (17 px), the Unlock and Plans dialogs (19 px, with clipping), and the Enzyme map (2 px).
3. **2.4.11 focus not obscured**: two controls in the Plans dialog at 320 px.
4. **1.4.3 contrast**: `.text-accent-foreground` in Study drill > Bedside & toxicology.
5. **Coverage holes**: 4 wcag22-checks worker chunks crashed during the full gate, so some routes have axe results only. Re-run with fewer workers.
6. **Layout shift (not a WCAG criterion, but it moves focus targets)**: on the home page, the client-only disclaimer aside and the header growing after hydration cause CLS of 0.27 on mobile.
7. **Not tested**: manual screen-reader passes (NVDA, JAWS, VoiceOver), voice control, Windows high-contrast/forced-colors mode, 400% zoom on desktop dialogs, and cognitive review. Automated tools catch only part of the success criteria.
8. **Export dose strings (content, not accessibility)**: the clinical packet dialog and EHR text include lab goals and a magnesium dose (`clinical-packet.ts:530-531`, `clinical-packet-dialog.tsx:428`). Flagged for the content owner.

## How to reproduce

```
npm run build && npm run preview -- --port 4173 --strictPort --host 127.0.0.1
AXE_FROM=<dir with axe-core> node scripts/a11y-gate.mjs http://127.0.0.1:4173 --json out.json
```

`scripts/a11y-gate.mjs` is on the `feat/a11y-gate` branch and is not on main yet.
