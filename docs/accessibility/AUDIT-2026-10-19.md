## Known gaps

Rechecked 2026-10-29 against main `9d8ce2c` (dev server, axe-core WCAG 2.x A/AA tags, and `scripts/wcag22-checks.mjs`). The lines below say what those checks found. This is not a conformance claim.

1. **2.5.8 target size**: the CSS fix (`fix/a11y-target-size`, PR #184) has since merged to main. The results above are from `ceefa83`, before it. Recheck: all 222 `/drug/` routes at 320 and 1280 px had 0 target-size failures under the same measurement as `scripts/wcag22-checks.mjs` (CYP role links and in-list pair links included). No further change.
2. **1.4.12 text spacing at 320 px**: Paxlovid pair pages (17 px) were addressed in #201 (`overflow-wrap: anywhere` on headings). Unlock and Plans dialogs were not rechecked here. Enzyme map on `9d8ce2c` was 9 px of sideways scroll with text spacing (column tracks sized to long unbreakable names). The map root now uses the same `overflow-wrap: anywhere` rule, and the column grid uses a shrinking track. Recheck of `/@Enzyme map` at 320 px: sideways 0 px, clipped 0.
3. **2.4.11 focus not obscured**: two controls in the Plans dialog at 320 px.
4. **1.4.3 contrast**: `.text-accent-foreground` in Study drill > Bedside & toxicology. On `9d8ce2c` the selected topic chip was still `#1c1915` on `#2f5d56` (about 2.35:1) because `text-accent-foreground` is not a theme color. It now uses the existing `text-accent-fg` token (`#f7f5ef` on `#2f5d56`, about 6.83:1). Axe `color-contrast` on `/@Study drill>Bedside & toxicology` was clear at 320 and 1280 px after that change.
5. **Coverage holes**: 4 wcag22-checks worker chunks crashed during the full gate, so some routes have axe results only. Re-run with fewer workers.
6. **Layout shift (not a WCAG criterion, but it moves focus targets)**: on the home page, the client-only disclaimer aside and the header growing after hydration cause CLS of 0.27 on mobile.
7. **Not tested**: manual screen-reader passes (NVDA, JAWS, VoiceOver), voice control, Windows high-contrast/forced-colors mode, 400% zoom on desktop dialogs, and cognitive review. Automated tools catch only part of the success criteria. `/recover` was included in the 2026-10-29 recheck (axe A/AA plus best-practice, and the wcag22 script, at 320 and 1280 px) and had no failures; that is not a screen-reader pass.
8. **Export dose strings (content, not accessibility)**: the clinical packet dialog and EHR text include the electrolyte-goals line and the magnesium line in the clinical packet export (being removed in #191). Flagged for the content owner.

## How to reproduce

```
npm run build && npm run preview -- --port 4173 --strictPort --host 127.0.0.1
AXE_FROM=<dir with axe-core> node scripts/a11y-gate.mjs http://127.0.0.1:4173 --json out.json
```

`scripts/a11y-gate.mjs` is on the `feat/a11y-gate` branch and is not on main yet.
