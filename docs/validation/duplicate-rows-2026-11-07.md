- **E1.** Auvelity is dextromethorphan with bupropion. The `auvelity` row already carries bupropion's CYP2D6 inhibition, dextromethorphan as the CYP2D6 victim, and the seizure-threshold flag; the second Auvelity row carried only serotonergic. It now carries the same roles, so the product reads the same whichever row search returns.
- **E2.** Samidorphan is the opioid antagonist in Lybalvi, and its section 4 contraindicates the product in patients using opioids. The `lybalvi` row carries the opioid-antagonist flag (precipitated withdrawal card with opioids); the second Lybalvi row did not, so Lybalvi with oxycodone or fentanyl showed only a sedation card. The CYP1A2 role is not copied (no saved source).
- **E3.** Searching "Epidiolex" returned the unbranded CBD row first, which grades CYP2C19 inhibition as strong. The Epidiolex label calls cannabidiol a moderate CYP2C19 inhibitor, which is what `cannabidiol-epidiolex` already says, and the 2026-10-19 audit kept `cannabidiol` strong because it is "unregulated CBD, not Epidiolex". The brand and alias now sit only on the Epidiolex row. No engine field changes, so no pair grade moves.
