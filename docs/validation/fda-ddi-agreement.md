## Method

1. FDA Table 1 rows were parsed from the page HTML and split per target (e.g. `2D6; 3A weak inhibitor` → two rows). FDA "3A" maps to our `CYP3A4` key. Only targets the catalog models are kept (CYP1A2, 2B6, 2C8, 2C9, 2C19, 2D6, 3A, P-gp); FDA lists no CYP2E1 examples. P-gp rows carry no FDA class, so only role presence is compared.
2. FDA names are resolved to catalog entries using the catalog's own `normalizeSearchText` + `stripSaltFormTokens`, tried against id → name → alias → brand, with `and` dropped so `lopinavir and ritonavir` ≈ `Lopinavir/ritonavir`. A short reviewed alias map covers `dabigatran etexilate`, `peginterferon alpha-2a`, `oral contraceptives` (→ `ethinyl-estradiol`). Enantiomers, active moieties (tenofovir), and single components of our combination products (trimethoprim) are deliberately not linked.
3. Each FDA (drug, target, role) pair is classified: `match`; `strength_mismatch` (same role, different class/grade); `direction_mismatch` (FDA inhibitor vs our inducer only, or vice versa); `missing_in_catalog` (no role of that kind on that target).

## Limitations

- FDA's Table 1 is **illustrative, not exhaustive** ("a guide and not considered a comprehensive list"). Absence from FDA is not evidence that a role is wrong; hence `not_in_fda` is informational only.
- FDA classes are defined by AUC change with index substrates; several depend on exposure conditions, preparation, or route (see FDA footnotes, e.g. grapefruit juice, ciprofloxacin/tizanidine, ritonavir). The catalog uses a coarser teaching scale; catalog `major` substrate is not a validated FDA class.
- CYP3A4 vs CYP3A: FDA grades CYP3A as a whole; the catalog keys it as CYP3A4.
- Only one catalog entry is compared per FDA name (the id/name match wins over release-form variants such as `-xr`).
- Educational teaching tool. **Not FDA-cleared**; not a substitute for prescribing information or a pharmacist.
